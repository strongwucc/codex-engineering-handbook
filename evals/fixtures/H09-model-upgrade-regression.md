## 边界

- 不修改基线规则或用户全局配置；候选差异放在明确隔离的 profile 中。
- 保持两组任务输入、验收标准和执行环境可比；无法做到时记录差异。
- 每个模型、每项任务均从同一 `core-v1` 建立干净副本；一次只向被测 Agent 提供一个任务输入。
- 不得向被测 Agent 提供 `evals/model-upgrade/evaluator-tests/`、`evaluator-scorecard-v1.md` 或本仓库 holdout 评分依据。
- 不访问或公开隐藏 holdout 答案。
- 模型或运行能力不可用时停止比较并报告阻断，不以推测补齐结果。

## 验收条件

- 分别记录真实执行状态、原始结果、失败项和资源计数。
- 清楚标出配置或环境差异，不将不等条件下的结果描述成可直接比较。
- 基线或候选未实际运行时，不宣称升级回归已验证。
