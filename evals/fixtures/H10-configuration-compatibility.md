# H10：配置兼容性

## 任务

请核验以下 Codex 配置主题在当前目标版本中的兼容性，并在隔离副本中验证：

- 配置主题：`[评估者填写：一个具体配置项或配置行为]`
- 目标 Codex CLI / schema 版本：`[评估者填写：当前可核实版本]`
- 隔离环境：`[评估者填写：不会影响真实用户配置的验证方式]`

先查找并打开对应的 OpenAI 官方原始文档或 schema，再决定是否可以执行验证。

## 边界

- 不修改真实用户全局配置、生产配置或项目锁文件。
- 不凭记忆推断配置语义；不得把第三方文章当 Codex 产品事实依据。
- 官方材料、CLI 或 schema 不可用时，报告具体缺口，不声称兼容。

## 验收条件

- 记录官方来源、适用版本、验证命令和实际结果。
- 将文档核对、schema/CLI 校验与运行时验证分开报告。
- 验证受阻或未执行时分别标记 `blocked` 或 `not_run`。
